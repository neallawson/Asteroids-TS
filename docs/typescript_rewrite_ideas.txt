This file is in the new typescript_rewrite branch. The design of this game is from 1996 and was designed with Java in mind, so this branch is for re-writing the project with typescript in mind.

This document is for capturing ideas related to the design and implementation of this re-write.
-Neal, 10/05/2023.
----------------------------------

New Interfaces:

Gameable/GameElementActions - Interface defining minimum actions GameEntities need to do.
reset(), die(), resurrect(), isAlive(), hide(), show(), tick(delta), paint()

Movable - Interface defining actions moving objects must implement.

Collidable - Interface defining GameEntity collision actions to be handled by the collision_handler():
- 
Timable Interface - Interface defining methods GameObjects must implement to use a timer.
   - function timer_handler(timer_name: string)

   ex: new_timer((timableObject, "test timer", 2));

        ...
        // 2 seconds later (timers are checked in the main game loop), a timer makes this call:
        timableObject.time_handler("test timer");

New Objects:
gameObjects - type {
   type: string
   collection: list[GameElement]
   properties: {} // map of properties that can be extended over time. static objects can set move=false, for example. hide=true turns off rendering call, etc.
}
